# Windows Event Log Investigation

## Objective
Investigate Windows Security logs to detect brute-force attempts and suspicious authentication activity.

## Tools Used
- Windows Event Viewer
- Sysmon

## Process
- Filtered logs by Event ID
- Identified failed logon patterns
- Documented findings and mapped them to MITRE ATT&CK

## Skills Demonstrated
- Log triage
- Threat detection
- MITRE mapping
