# Nmap Network Scan Lab

## Objective
Perform reconnaissance and enumeration on a target machine to identify open ports, running services, and potential vulnerabilities.

## Tools Used
- Nmap
- Kali Linux VM

## Process
- Ran basic scans (SYN, version detection)
- Identified open ports and services
- Interpreted results and mapped them to potential risks

## Skills Demonstrated
- Reconnaissance
- Service enumeration
- Documentation
